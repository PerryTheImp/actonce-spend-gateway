# Contributing to ActOnce Spend Gateway

Thank you for considering a contribution. This project is early — every issue, PR, and suggestion matters.

## How to contribute

1. **Open an issue first.** Bug reports and feature requests help us track what the community needs.
2. **Fork the repo** and create a branch: `git checkout -b feature/your-feature-name`
3. **Write tests.** Every PR should include tests for new behaviour.
4. **Run the test suite:** `npm test`
5. **Open a pull request** with a clear description of what changed and why.

## Development setup

```bash
git clone https://github.com/PerryTheImp/actonce-spend-gateway.git
cd actonce-spend-gateway
npm install
npm run build
npm test
```

## Areas where help is especially welcome

- MCP server integration improvements
- Additional agent framework examples
- Policy rule expansions
- Documentation and translations
- Performance optimisations

## Code style

- TypeScript strict mode
- No `any` types without justification
- Clear error messages
- Document public APIs with JSDoc

## Questions?

Open an issue or email hello@actonceapi.com.
